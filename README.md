## Summary
In this lab we learned how to implement a Mux and Demux, as well as how to connect the output of one to the input of another. This allows for transfer of information from 1 of many objects, to 1 of many other objects. 

## Lab Questions

### In plain English describe the function and use of a multiplexer.
A multiplexer allows us to choose from one of multiple inputs for a single output. This has many uses, like switching between internet users or multiple light switches for one light.

### In plain English describe the function and use of a demultiplexer.
A demultiplexer allows us to send one input to one of multiple outputs. This function is used in many places, such as plumbing, where you have one input of water, to different outputs.

### What other uses might these circuits have? (Think Shannon’s)
With Shannon's rule it is possible to convert everything to a mux and demux. This is also true in the opposite. We will be able to use these to implement any circuit.
